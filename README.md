### Open source

I use open source every day, so I try to give back: report bugs with a minimal repro, improve docs where I got stuck, and send small, well-tested pull requests.

**Tools I maintain**

| Project | What it does | Stack |
|---|---|---|
| **[UsageMeter](https://github.com/OmerYasirOnal/UsageMeter)** | Native macOS menu-bar app that tracks Claude usage. Free, private, no telemetry. Installable via [Homebrew](https://github.com/OmerYasirOnal/homebrew-tap). | Swift · SwiftUI |
